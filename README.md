# Home Helper

A mobile-first household coordination app built as a Lean In Circle vibe-coding demonstration.

## Phase 1: local demo

This is a fully interactive **DEMO MODE** using fictional household data stored only in the browser. It has no accounts, Firebase connection, real household data, cross-device sync, or production authorization.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use the Employer / Helper control in the header to explore both demo views. Use **Reset demo data** to restore fictional sample data.

## Privacy

The demo collects no location, camera, microphone, or personal household data. Scheduled times are planning targets, not activity surveillance. Future Firebase integration must use authenticated, household-scoped access controls; a UI role toggle is never real authorization.
